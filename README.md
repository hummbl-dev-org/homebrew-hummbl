# homebrew-hummbl

Homebrew tap for HUMMBL CLI tools.

## Usage

```bash
brew tap hummbl-dev/hummbl
brew install arbiter
brew install bif
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| [arbiter](Formula/arbiter.rb) | Agent-aware code quality scoring for multi-agent codebases |
| [bif](Formula/bif.rb) | Batch Ingestion Framework for structured technical knowledge acquisition |

## Canonical Tap

This repository (`hummbl-dev/homebrew-hummbl`) is the **canonical** Homebrew tap for HUMMBL CLI tools. All formula work, CI, and documentation should land here.

The sibling repository `hummbl-dev/hummbl-homebrew` is **deprecated** and will be archived. It previously held a CODEOWNERS file that has been migrated here. No new work should land in `hummbl-homebrew`.

**Operator decision (2026-07-24):** `homebrew-hummbl` is canonical; `hummbl-homebrew` will be archived after unique content migration is complete.
